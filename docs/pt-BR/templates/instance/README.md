# Projeto conduzido com Seedtrail

Para entender **o produto**, abra o [mapa](../README.md). Ele aponta ao que existe, ao que foi definido, às fontes responsáveis e ao que continua aberto. Não é necessário ler os arquivos internos do kit primeiro.

Para **continuar o trabalho**, leia [AGENTS.md](AGENTS.md), o mapa e o pedido atual. O assistente lê a configuração em .kit/project.json, seleciona a [skill pertinente](../../process/SKILLS.md) e consulta somente as fontes necessárias. Se houver trabalho selecionado, seu handoff explica a retomada; estado JSON registra andamento/evidências.

Entregas de conteúdo ficam em docs/product/. .kit contém instruções, scripts e modelos genéricos: modelos não são resultados do projeto. A [organização](../../process/ORGANIZATION.md) explica os destinos; [ciclos](../../process/WORK_CYCLES.md) explica condução, parada e preservação de provas.

Ao haver produto executável, substituir esta introdução por propósito, uso e limitações reais, mantendo o link para o mapa. Uma ideia/serviço sem código não precisa de comandos fictícios, arquitetura de software ou todas as pastas.

Idioma das entregas vem da configuração, português por padrão; nomes técnicos em inglês. Helpers usam PowerShell 7.2+; ferramentas de pesquisa/renderização/runtime dependem do trabalho. O método também pode ser conduzido manualmente. [.kit/LICENSE](../../../../LICENSE) e [.kit/CREDITS.md](../../CREDITS.md) cobrem o framework, sem impor licença ao produto/dados.
