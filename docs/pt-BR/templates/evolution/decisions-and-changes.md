Registrar críticas, resultados, escolhas e mudanças. Distinguir proposta do assistente de decisão do fundador. Identificar substituições/retificações sem manter relações falsas.

Para mudança: motivo → alcance → decisão/spec → tarefa/verificação → documentos/release → resultado. Ajuste pequeno não reinicia descoberta inteira; nova direção exige revisitar hipóteses.

Saída: motivo recuperável, fonte responsável e próximos passos concretos.

Para decisões já registradas em um trabalho ou ADR, esta tabela aponta à fonte e ao estado/sucessora; não copiar novamente alternativas/motivos. Usar como fonte própria somente para decisão transversal sem registro responsável existente. Conhecimento vigente descreve o resultado aplicável; este índice preserva consulta da origem.
