# Seedtrail 0.1.0: review and limits

Seedtrail is an independent personal experiment developed with Codex. It combines proportionate product discovery, current knowledge and bounded changes with evidence. It does not replace research with real users, automatically run an assistant or establish approval through generated documents.

## Checks performed

- Four specialist subagents examined clarity, method references, continuation and independent reading. These were AI reviews, not observations of a human team.
- Helper tests on Windows/PowerShell 7.6.5: **39 passed**. They cover lean initialization, on-demand generation, ID collision, scope/round limits, pause/resume, stale writes, evidence integrity and copied-instance independence.
- Documentation fixtures: **15 passed**. They cover broken links, obsolete references, language/source drift, consumed JSON and explicit historical imports. The checker verifies structure, not semantic sufficiency.
- A bounded Node/SQLite equipment-reservation scenario planned the complete MVP before code, implemented three operations, changed the occupancy rule and preserved examined versions. Actual test evidence distinguishes local execution from planned web/authentication/inventory features. It does not prove a commercially useful product or all methods/stages.
- Synthetic reuse/reading and integration exercises informed the current organization. Neither local Git fixtures nor an assistant retrieving a source prove human collaboration, CI hosting or native discovery in every client.

Comparative exercises against other frameworks were exploratory and used synthetic scenarios with AI participants. Their conclusions depend on the setup and the tested scenario; they are not an independent evaluation, a general ranking or evidence of Seedtrail superiority. No claim of compatibility or complete lifecycle coverage follows from these exercises.

## Findings incorporated

One current feature page holds its behavior, business rules, acceptance and pertinent design, with a short history. Changes reference that source and retain differences, execution and evidence. Closed work is not reopened as a new implementation. The method can plan several features before implementing any; feature granularity follows the product rather than a mandatory taxonomy.

Helpers reject duplicate IDs but do not detect semantic duplication across different names. Closure checks examined bytes and preserves mutable external sources. Editing a previously recorded source requires actual re-review before closure; hashes must not be refreshed to pretend the old review still applies.

Lean initialization leaves the auxiliary authority register on demand. Use it only when the responsible map/source is insufficient, such as importing legacy sources. Historical imports require explicit file paths under docs/product/sources and verified SHA256 hashes; their old instructions are data, not current commands.

Design procedures address meaningful states, accessibility, content and viewport constraints, visual-contract implementation and selective critique. Referenced books and third-party agents are not redistributed. Heuristics or a checklist do not establish WCAG compliance without checking the real interface.

## Coverage and continuation

Eleven [procedures](process/SKILLS.md) cover guidance, research, assumptions, feasibility, UX, brand/design, engineering, security, delivery, evolution and knowledge maintenance. Choose specialists only when scope/technology requires them. More agents or files are not evidence of better coverage.

[Methods](process/METHODS.md), [knowledge organization](KNOWLEDGE.md) and [feature documentation](FEATURE_DOCUMENTATION.md) distinguish adopted practices from local file/schema choices. SDD, contextual TDD, ADR, Docs as Code and selective architectural views contribute to different needs; no single reference defines the complete Seedtrail workflow.

Name screening found no direct software competitor in the returned results. This is not trademark/domain clearance. Sources, inspirations and reuse limits are in [credits](CREDITS.md).

## Remaining limits

No real participant study, investment validation, production deployment, formal security certification or cross-platform runtime matrix was completed. Native Codex CLI discovery was not demonstrated in the restricted trial; Linux helpers need PowerShell. More realistic concurrent authors, human comprehension and long-term maintenance still require direct evaluation.

Keep unique sources and verified conclusions. Disposable instances and raw preliminary audit logs are outside the reusable distribution; reproducible framework tests remain in tests. Changes to the method must update affected instructions, translations, catalog hashes and tests before distribution.
