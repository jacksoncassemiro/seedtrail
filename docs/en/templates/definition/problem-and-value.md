# Problem, audience and value proposition

Status: to author. Inputs: context and research.

State audience/circumstance/problem/impact and alternative limitations. Separate reports from hypotheses. Initial personas are candidate profiles, not interviewed people.

Define desired job/progress (JTBD), pains/gains and proposed benefit; compare existing solutions and simple alternatives. Prioritize opportunity by evidence, importance and feasibility rather than feature count.

Output: value proposition, initial scope, alternatives, evidence/hypotheses and the question the next test must answer. Record limits and decisions.
