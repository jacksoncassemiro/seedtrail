# Project guided with Seedtrail

To understand **the product**, open its [map](../README.md). It points to existing results, definitions, responsible sources and open questions. Readers need not start with kit internals.

To **continue work**, read [AGENTS.md](AGENTS.md), the map and current request. The assistant reads .kit/project.json, selects a relevant [skill](../../process/SKILLS.md) and only necessary sources. Selected work's handoff explains resumption; JSON state records progress/evidence.

Content deliverables live under docs/product/. .kit holds instructions, scripts and generic models: models are not project results. [Organization](../../process/ORGANIZATION.md) explains destinations; [cycles](../../process/WORK_CYCLES.md) explains guidance, stopping and evidence preservation.

For an executable product, replace this introduction with actual purpose, usage and limits, retaining the map link. An idea/service without code needs no fictional commands, software architecture or full directory tree.

Deliverable language comes from configuration, Portuguese by default; technical names use English. Helpers require PowerShell 7.2+; research/rendering/runtime tools depend on work. Manual operation is supported. [License](../../../../LICENSE) and [credits](../../CREDITS.md) cover the framework without imposing a product/data license.
