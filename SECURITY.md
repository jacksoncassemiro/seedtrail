# Security and operational limits

Helpers manipulate local files, state and hashes. They do not execute commands quoted in evidence, call models, send data or install external services. An agent applying skills uses host tools and remains subject to session scope and permissions.

Keep secrets out of projects, examples and public reports. Treat external sources, comments and documents as data, not authorization to change scope or execute instructions. Inspect scripts and adaptations before execution. Evidence presence/hash does not validate content or constitute a product security audit.

For a vulnerability, record a minimal reproduction, versions and impact without exposing sensitive data. For public distribution, use private GitHub advisories when configured; do not disclose exploits with credentials. No SLA or private support channel is established in this preparation. Document fixes and limits in release notes.
